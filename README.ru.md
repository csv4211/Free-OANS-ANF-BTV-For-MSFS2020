# AMDB OANS

[English](README.md) · [Русский](README.ru.md)

Локальная движущаяся карта аэродрома для Microsoft Flight Simulator 2020 — OANS FlyByWire A380 в самолёте и веб-карта на ПК.

Исходный код, документация и обновления: https://github.com/csv4211/Free-OANS-ANF-BTV-For-MSFS2020

## Что умеет

- **OANS в самолёте** — подаёт карты AMDB в ND/OANS FlyByWire A380 во время руления.
- **Веб-карта** — те же данные в браузере, позиция самолёта через SimConnect и простой маршрутизатор руления.
- **Онлайн-сервер** — карты загружаются с AMDB-сервера.
- **Автообновление** — при запуске программа сама проверяет новую версию и устанавливает её.
- **Доступ устройства** — при первом запуске регистрируется этот ПК; в окне переключатель языка EN / RU.

## Требования

- Интернет до AMDB-сервера
- Права **администратора** только если включаете **OANS в самолёте** (hosts и порт 443). Веб-карта работает без админа.

## Быстрый старт

1. Скачайте `AmdbOansClient.exe`.
2. Запустите.
3. Дождитесь статуса ready / server online.
4. Включите **Web map** и/или **OANS in the aircraft**.
5. Для OANS: запустите сим с FBW A380 и откройте OANS/ND как обычно.

Рекомендуется запускать `AmdbOansClient.exe` до старта симулятора.

## Замечания

- Если Windows SmartScreen ругается при первом запуске: *Подробнее* → *Выполнить в любом случае* (сборка без подписи).
- Антивирус может ругаться на MITM-хелпер для OANS; он активен только пока включён OANS и работает локально.

## Поддержка

Если активация не проходит или карта пустая — проверьте, что origin-сервер онлайн и у вас нужная версия клиента (при новой сборке программа должна обновиться сама).
